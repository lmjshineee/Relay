# CS146S 与 Relay 的学习搭配

建议选学，边做 Relay 边参考。你的当前目标是看懂并写出 agent 循环，因此先跟课程的相关内容做实验，遇到具体问题再补其余主题。

资料核对日期：2026-10-23。[课程官网](https://themodernsoftware.dev/) 当前展示 Fall 2026，保留 [Fall 2025](https://themodernsoftware.dev/fall2025) 入口。下面的周次以 2026 课表为准；不把 2025 课表混成今年安排。核对范围是官网介绍及其页面脚本中的课表，没有逐份观看讲座或验证所有外链的公开访问权限。

### 1. 值得借鉴什么

| 官方课表内容 | 在 Relay 中怎么练习，这是本项目的建议 |
|---|---|
| Week 1：agent 内部循环、核心工具、系统提示 | 对照第一批代码追踪一次请求和观察；接真实模型后再判断它是否理解了工具结果 |
| Week 2：上下文、开发规格、工具设计和 MCP | 对比清晰与含糊的工具说明，固定任务后观察无效调用次数；先看懂本地工具再考虑通信协议 |
| Week 4–5：仓库指令、检查机制、便于 agent 工作的代码库 | 给任务写明确输入、预期行为和检查命令，让结果能被复现 |
| Week 6–7：代码审查与安全 | 加入写入能力后，检查边界案例、提示注入和越权请求，避免只根据模型的完成声明判断结果 |

这些主题可在[官网 Syllabus](https://themodernsoftware.dev/) 中核对。按当前日期，2026 Week 6 及以后的项目仍是课表安排，不能把安排当成已经完成的公开教学内容。

### 2. 推荐程度与适用边界

我的判断是：它很适合补充“如何围绕 coding agent 组织软件开发”，也能为工具设计、上下文和验证提供练习方向。官网介绍强调实践、项目和从业者分享，并要求相当于 CS111/CS161 的编程经验。因此对刚开始写 Python 的人，更合适的方式是先做一个小循环，再选对应主题看。

从课表覆盖判断，它没有系统承诺讲完 Relay 所需的进程崩溃恢复、事务、动作对账和严格成本评测。这部分仍沿用本仓库的开发计划逐步实现；不要把看完课程等同于掌握这些系统能力。这个判断来自课程范围对比，不是对全部授课质量的评价。

### 3. 现在怎么搭配

1. 今天先跑 [第一批](06-first-batch-learning.md)，完成四个实验；对应 2026 Week 1。
2. 接真实模型时看 Week 2，把“工具错误会不会促使下一步调整”作为一个实际观察题。固定 fixture，保存完整轨迹，区分预写脚本与模型自己选择的动作。
3. 加写文件、执行测试前，参考已列出的仓库规范与安全主题；后续审查课程材料公开后再选读。恢复与评测继续按 Relay 计划做。

现阶段无需为了跟课先引入多个 agent 或完整 MCP 服务。先能解释当前小循环，再决定哪一层抽象能解决手头的问题。
